이 저장소는 `artist_exhibition_platform_plan_ko.docx`와 작가 스케치를 바탕으로 만든 실행 가능한 첫 버전입니다. 상품 전체의 최종 완성을 뜻하지 않습니다.

## 구조와 데이터

`server/index.js`가 HTTP, 계정, 권한, 프로젝트 API를 담당합니다. `node:sqlite`를 사용해 런타임 npm 의존성을 없앴습니다. `public`은 브라우저 ES 모듈과 CSS이고, `workers/image_tools.py`는 별도 프로세스에서 업로드 검증, 영역 선택, 누끼, QR을 처리합니다.

SQLite에는 users, sessions, sites, versions, assets 테이블이 있습니다. 전시 구조는 버전이 있는 JSON으로 저장합니다. 작품 영역은 좌상단 원점의 0~1 좌표이며 SVG에서는 1000×1000 좌표로 변환합니다. 이미지가 반응형으로 바뀌어도 영역이 같은 상대 위치에 남습니다. 윤곽과 구멍은 even-odd 규칙으로 처리합니다.

계정 비밀번호는 scrypt+개별 salt로 해시하고 세션 토큰은 SHA-256 해시만 DB에 보관합니다. 쿠키는 HttpOnly/SameSite=Lax이며 운영 모드에서 Secure를 붙입니다. 변경 API는 요청 Origin을 확인합니다. 사용자 업로드는 소유자만 읽을 수 있으며 공개된 전시에 사용된 웹용 이미지에 한해 관람객 읽기를 허용합니다. 원본은 소유자에게만 제공됩니다. API 키는 서버 환경변수로만 읽습니다.

관람객은 이미지 모델이나 번역 API를 호출하지 않습니다. 작가가 확인하고 저장한 영역과 텍스트만 전달받습니다. 원본 그림을 수정하지 않고 누끼 결과를 새 이미지로 저장합니다.

## 검증 기록

작성 환경에서 Node 24.19.0, Python 3.12.14로 `npm run check`와 `npm test`를 실행했고, 통합 테스트 13개가 통과했습니다. 색상 선택, 실제 이미지 업로드·원본 보존·누끼와 QR은 실제 Python 처리기를 실행했습니다. 번역 API 호출은 가짜 응답으로 요청 형식과 서버 자격증명 처리를 검증했습니다.

SAM 2 추론, 실제 DeepL 요청, Docker 빌드, GitHub Actions와 실제 브라우저 E2E는 이 환경에서 실행 검증하지 못했습니다. Chromium 다운로드가 네트워크 제한으로 차단되어 Playwright 실행에 필요한 브라우저가 설치되지 않았습니다. 브라우저 테스트 스크립트와 CI 구성을 포함했으며 별도 환경에서 실행해야 합니다. 브라우저 테스트가 실행되기 전에는 화면과 편집 흐름을 완전히 검증했다고 볼 수 없습니다.

작업 시점 GitHub 연결은 관리자 설정으로 사용할 수 없어 원격 저장소 생성과 업로드를 수행하지 않았습니다. `docs/GITHUB.md`에 개인 계정에서 업로드하는 방법이 있습니다.
